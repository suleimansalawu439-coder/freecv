# FreeCV Job Matcher Chrome Extension

This extension allows you to instantly extract job descriptions from LinkedIn and Indeed and score your FreeCV resume against them.

## Installation Instructions

1. Open Chrome and navigate to `chrome://extensions/`
2. Turn on **Developer mode** (toggle in the top right corner).
3. Click the **Load unpacked** button in the top left.
4. Select this `chrome-extension` folder.
5. Pin the FreeCV extension to your browser toolbar.

## Usage

1. Navigate to any job posting on **LinkedIn** or **Indeed**.
2. Click the FreeCV extension icon in your toolbar.
3. Click **Score My Match**.
4. You will be redirected to the FreeCV Builder with the job description pre-filled in the ATS Grader!
